# DsSearchField — Cogniterm Design System

import { DsSearchField } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
목록 상단·GNB 검색. 전역이면 CommandPalette와 연동.

## Props
- modelValue: string = '' — v-model.
- placeholder: string = '검색…' — 안내.
- shortcut: string — ⌘K 힌트 — 포커스 전에만 표시.
- loading: boolean = false — 검색 중 스피너.
- size: 'sm' | 'default' = 'default' — 컨트롤 스케일 — 기본 32 / md 36 / lg 40 (sm은 32의 다른 이름).

## Events
- @search (string) — Enter 시 발생.

## 사용 예
```vue
<DsSearchField v-model="q" shortcut="⌘K" :loading="searching" @search="run" />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 공용/부품/DsSearchField.vue — 이름은 같지만 다른 부품 — 검색 범위(scope · scopeOptions)를 칸 안에 품고 @submit. DS 의 shortcut · loading · @search 는 없습니다

## 구분
- vs Input: 검색이 아닌 일반 입력은 Input

## 지침
- [해야 할 것] 전역 검색은 CommandPalette와 연결 — 같은 ⌘K.

## 접근성
키보드: Enter=검색 실행 · Esc=브라우저 기본 — 값 지움
직접 처리: 결과 수를 aria-live로 알리기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
