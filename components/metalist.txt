# DsMetaList — Cogniterm Design System

import { DsMetaList } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
상세 패널의 키-값 — 이벤트·문서·에이전트 속성.

## Props
- items: MetaItem[] = 필수 — { label, value, mono? }

## Slots
- #(label) — 해당 라벨 값을 커스텀 렌더 (배지 등).

## 사용 예
```vue
<DsMetaList :items="[
  { label: '수행자', value: 'Jiyong Kim' },
  { label: '이벤트 ID', value: 'evt_8f3a2c91', mono: true },
]" />
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<dl class="metalist">
  <div class="metalist-row"><dt>수행자</dt><dd>Jiyong Kim</dd></div>
</dl>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)

## 구분
- vs DetailTable: 같은 열을 가진 줄이 여럿이면 DetailTable

## 지침
- [해야 할 것] ID·IP·시각은 mono로.

## 접근성
직접 처리: 라벨을 짧게 — 88px 폭

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
