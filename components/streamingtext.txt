# DsStreamingText — Cogniterm Design System

import { DsStreamingText } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
스트리밍 중인 응답 본문.

## Props
- done: boolean = false — true가 되면 커서를 제거합니다.

## Slots
- #default — 지금까지 도착한 텍스트.

## 사용 예
```vue
<DsStreamingText :done="!isStreaming">{{ text }}</DsStreamingText>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<div class="msg-text">
  스트리밍 중인 텍스트<span class="cursor"></span>
</div>
<!-- 완료되면 .cursor 제거 -->
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 완료되는 즉시 커서를 없앱니다. 남아 있으면 멈춘 것처럼 보입니다.

## 접근성
직접 처리: 부모 영역에 aria-live="polite" — 도착하는 대로 읽어줌 / 커서는 aria-hidden / aria-busy로 생성 중임을 알리기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
