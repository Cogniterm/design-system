# DsDetailTable — Cogniterm Design System

import { DsDetailTable } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
상세 화면 안의 표 — 사용 내역 · 구성 · 이력.

## Props
- columns: DetailColumn[] = 필수 — { key, label, align? } — 숫자 열은 align: 'right'.
- rows: Record[] = 필수 — 줄 데이터. 빈 값은 "—"로 그립니다.
- rowKey: string — 줄 구분 키 — 없으면 순번.

## Slots
- #(열 key) — 그 열 칸을 직접 그림 — { row, value }. 배지 · 링크 등.

## 사용 예
```vue
<DsDetailTable
  :columns="[{ key: 'model', label: '모델' }, { key: 'calls', label: '호출' }, { key: 'cost', label: '비용', align: 'right' }]"
  :rows="usage" row-key="model" />
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<div class="jtw">
  <table class="jt">
    <thead><tr><th>모델</th><th class="num--right">비용</th></tr></thead>
    <tbody><tr><td><b>gpt-4.1</b></td><td class="num--right">₩48,210</td></tr></tbody>
  </table>
</div>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)

## 구분
- vs DataTable: 정렬 · 선택 · 쪽 넘김이 필요한 목록이면 DataTable
- vs MetaList: 열이 없는 키-값 나열이면 MetaList

## 지침
- [해야 할 것] 숫자 열은 머리와 칸 모두 오른쪽(num--right).
- [해야 할 것] 빈 칸은 "—" — 0으로 채우지 않습니다.
- [하지 말 것] 머리 행에 회색 면을 깔지 않습니다 — 1px 밑선만.
- [하지 말 것] 정렬 · 선택 · 쪽 넘김이 필요하면 이게 아니라 DataTable입니다.

## 접근성
직접 처리: 표가 무엇인지 앞의 절 제목으로 알리기 — 표 혼자 두지 않기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
