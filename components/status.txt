# DsStatus — Cogniterm Design System

import { DsStatus } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
표의 상태 열 — 연결 · 정책 · 계정의 지금 상태.

## Props
- tone: 'neutral' | 'ok' | 'wait' | 'err' | 'off' = 'neutral' — ok 정상 · 활성 / wait 대기 · 확인 필요 / err 오류 / off 일시정지 · 비활성.

## Slots
- #default — 상태 낱말 — 정상 · 일시정지 · 활성 · 비활성.

## 사용 예
```vue
<DsStatus tone="ok">정상</DsStatus>
<DsStatus tone="off">일시정지</DsStatus>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<span class="state ok">정상</span>
<span class="state off">일시정지</span>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)

## 구분
- vs Badge: 실행 한 번의 결과면 Badge — Status는 지금 상태

## 지침
- [해야 할 것] 상태는 지금의 모습입니다 — 정상 · 일시정지 / 활성 · 비활성. 실행 한 번의 결과(완료 · 실패)는 Badge.
- [해야 할 것] 글자를 늘 함께 씁니다 — 점 색만으로는 읽을 수 없습니다.
- [하지 말 것] 실행 결과에 "정상"을 쓰지 않습니다.

## 접근성
직접 처리: 상태 낱말을 늘 함께 — 점 색만으로 뜻을 전하지 않기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
