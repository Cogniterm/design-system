# DsFileRow — Cogniterm Design System

import { DsFileRow } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
드라이브 리스트 보기 — 세부 비교용.

## Props
- name: string = 필수 — 파일 이름.
- meta: string — 크기·날짜 등.
- icon: IconName — 어떤 아이콘인지 알려주는 값. 실제 그림은 #icon 슬롯이 그립니다.
- selected: boolean = false — 선택 상태.
- checkbox: boolean = false — 다중 선택 피커에서 앞에 체크박스를 노출.
- disabled: boolean = false — 선택 불가 — 흐리게, 클릭 안 됨.

## Events
- @select — 행 클릭 (disabled면 발생 안 함).
## Slots
- #icon — 파일 아이콘. 을 넣습니다. 생략하면 아이콘 자리가 비어 있습니다.
- #trailing — 이름 뒤 우측 부가 정보 — 배지·상태 (예: CSO 등급).

## 사용 예
```vue
<DsFileRow v-for="f in files" :key="f.id"
  :name="f.name" :meta="f.meta"
  :selected="isSelected(f)" @select="toggle(f)"&gt;
  <template #icon><DsIcon :name="f.icon" size="sm" /></template>
</DsFileRow>
```

## 지침
- [해야 할 것] 42px 행을 유지해 많은 파일을 훑기 좋게 합니다.

## 접근성
키보드: Tab=행으로 이동 · Enter=열기 · Space=선택
직접 처리: 행 전체가 클릭 가능하면 <a> 또는 <button>으로 / 선택 상태를 aria-selected로

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
