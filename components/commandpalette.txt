# DsCommandPalette — Cogniterm Design System

import { DsCommandPalette } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
전역 ⌘K — 문서·에이전트·명령으로 점프.

## Props
- modelValue: boolean = false — 열림.
- items: PaletteItem[] = 필수 — { id, title, group?, hint? }
- placeholder: string — 입력 안내.
- limit: number = 30 — 결과 상한 — 넘치면 목록이 스크롤됩니다.

## Events
- @select (PaletteItem) — 선택 시. 팔레트는 자동으로 닫힘.

## 사용 예
```vue
<DsCommandPalette v-model="open" :items="commands" @select="run" />
<!-- 전역: keydown ⌘K → open = true -->
```

- 관리자 콘솔 (Vuetify 없음): 쓸 수 없음 (Vuetify 없음) — 대응 부품이 없으면 먼저 물어보세요

## 접근성
키보드: ⌘K=열기 (앱에서 바인딩) · ↑ ↓=이동 · Enter=실행 · Esc=닫기
직접 처리: 전역 단축키 등록은 앱 몫 / 최근 사용 상단 정렬

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
