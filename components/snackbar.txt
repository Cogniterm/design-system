# DsSnackbar — Cogniterm Design System

import { DsSnackbar } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
저장·삭제 결과 알림. 후속 액션은 하나까지.

## Props
- modelValue: boolean = false — v-model로 열고 닫습니다.
- variant: 'success' | 'danger' = 'success' — 결과 종류.
- action: string — 후속 액션 라벨. 하나까지.
- timeout: number = 내용에 따라 — 자동 닫힘(ms). 주지 않으면 행동 버튼이 없을 때 3000, 있을 때 6000입니다 — 되돌리기를 누르려는 순간 사라지지 않게.

## Events
- @action — 액션 클릭.
## Slots
- #default — 문구.

## 사용 예
```vue
<DsSnackbar v-model="open" variant="success" action="View" @action="go">
  에이전트를 추가했습니다.
</DsSnackbar>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): window.toast() (공용/toast) · Vue 화면은 공용/부품/Toaster.vue — 알약 모양 — 자리는 쓰는 쪽(가운데 아래)

## 구분
- vs Toast: 같은 생김새입니다 — Snackbar가 Toast를 그대로 그립니다. 띄우고 없애는 동작이 필요하면 Snackbar
- vs Alert: 지나가도 되면 Snackbar, 남아야 하면 Alert

## 지침
- [해야 할 것] 삭제처럼 되돌릴 수 있는 작업에는 Undo 액션을 답니다.
- [하지 말 것] 동시에 여러 개를 띄우지 않습니다. 큐로 하나씩 처리합니다.

## 접근성
키보드: Tab=액션으로 이동
직접 처리: 중요한 정보는 Snackbar에 담지 않기 — 사라집니다 / 액션은 하나까지

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
