# DsChatMessage — Cogniterm Design System

import { DsChatMessage } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
챗 화면. 툴콜은 본문 위에 — 근거가 답보다 먼저.

## Props
- role: 'user' | 'agent' = 'agent' — user는 오른쪽 회색 풍선, agent는 풍선 없는 본문.
- streaming: boolean = false — true면 끝에 깜빡이는 커서.

## Slots
- #default — 메시지 본문.
- #tools — 응답 위에 들어가는 ToolCallStep 목록.

## 사용 예
```vue
<DsChatMessage role="user">
  지난달 계약서 파일 찾아서 요약해줘
</DsChatMessage>

<DsChatMessage role="agent" :streaming="isStreaming">
  <template #tools>
    <DsToolCallStep status="done">search_drive("계약서", June) — 3 files</DsToolCallStep>
  </template>
  6월에 체결된 계약서 3건을 찾았습니다<DsCitationChip :index="1" />
</DsChatMessage>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<!-- 사용자 — 오른쪽 회색 풍선 -->
<div class="msg msg-user"><div class="msg-bubble">질문 텍스트</div></div>

<!-- 에이전트 — 풍선 없는 본문, 툴콜은 위에 -->
<div class="msg msg-agent"><div class="msg-body">
  <div class="msg-text">응답<span class="cursor"></span></div>
</div></div>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 글로벌 표준(Claude·ChatGPT·Gemini) — 아바타·이름표 없이 정렬로 화자를 구분합니다.
- [해야 할 것] 툴콜은 본문 위에. 무엇을 근거로 답했는지가 답보다 먼저 보여야 합니다.
- [하지 말 것] 에이전트 응답을 풍선에 넣지 않습니다. 긴 응답이 풍선에 갇히면 읽기 어렵습니다.

## 접근성
키보드: Tab=메시지 내 링크·인용 칩으로 이동
직접 처리: 스트리밍 영역에 aria-live="polite" — 응답 도착을 읽어줌

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
