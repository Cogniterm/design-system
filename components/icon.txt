# DsIcon — Cogniterm Design System

import { DsIcon } from '~/design/icon'   // Vuetify 불필요 · ds.css만 · @lucide/vue 필요

## 용도
아이콘이 필요한 모든 곳. 의미 이름으로 부르고, 없으면 vue/icons.ts에 등록합니다.

## Props
- name: IconName = 필수 — 의미 이름. 'delete', 'agent', 'search' 등. vue/icons.ts에 등록된 것만.
- size: 'sm' | 'md' | 'lg' | number = 'md' — 16 / 20 / 24px. 그 사이 값은 픽셀 그리드가 어긋납니다.
- label: string — 뜻을 전달하는 아이콘이면 필수. 없으면 aria-hidden 처리됩니다.
- spin: boolean = false — 회전. loading 아이콘에 씁니다.


## 사용 예
```vue
import { DsIcon } from '~/design/icon'

<DsIcon name="delete" />
<DsIcon name="agent" size="lg" />
<DsIcon name="loading" spin />
<DsIcon name="search" label="검색" />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design/icon · html 문법)


## 지침
- [해야 할 것] 같은 뜻에는 항상 같은 아이콘을 씁니다. 새 아이콘은 vue/icons.ts에 의미 이름으로 등록합니다.
- [해야 할 것] 아이콘은 옆 글자와 같은 색(currentColor)을 씁니다. 아이콘만 브랜드 색으로 칠하지 않습니다.
- [접근성] 뜻을 전달하는 아이콘에는 label을, 장식이면 생략합니다(자동으로 aria-hidden).
- [하지 말 것] 16/20/24 외의 크기를 쓰지 않습니다. 18px, 22px는 픽셀 그리드가 어긋나 흐려집니다.

## 접근성
직접 처리: 뜻을 전달하는 아이콘에는 label 필수 / 장식이면 label을 비워두기 (자동 숨김)

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
