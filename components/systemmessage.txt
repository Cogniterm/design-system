# DsSystemMessage — Cogniterm Design System

import { DsSystemMessage } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
대화 스트림 속 시스템 안내 — 요약됨·초기화됨.

## Props
- time: string — 옆에 붙는 시각.

## Slots
- #default — 안내 문구.

## 사용 예
```vue
<DsSystemMessage time="09:14">이전 대화가 요약되었습니다</DsSystemMessage>
```

## 구분
- vs Alert: 에러·경고는 Alert

## 지침
- [하지 말 것] 에러를 시스템 메시지로 흘리지 않습니다 — Alert로.

## 접근성
직접 처리: 에러는 여기 말고 Alert로

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://kimjiyong995-coder.github.io/design-system/llms.txt
