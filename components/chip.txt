# DsChip — Cogniterm Design System

import { DsChip } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
활성 필터 표시, 첨부 파일 목록, 선택된 태그.

## Props
- variant: 'default' | 'brand' = 'default' — 걸린 필터 조건은 brand — 제품의 조건 칩 줄은 면을 벗기고 브랜드 선 + 글자(28px · 네모)로 씁니다. 첨부처럼 중립 표시는 default.
- removable: boolean = true — ✕ 버튼 표시.

## Events
- @remove — ✕ 클릭 시 발생.
## Slots
- #default — 칩 라벨.

## 사용 예
```vue
<DsChip @remove="detach(file)">design-system.pdf</DsChip>
<DsChip variant="brand" @remove="clearFilter">Status: Running</DsChip>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<span class="chip">
  design-system.pdf
  <button class="x" aria-label="Remove"><svg class="lic " width="12" height="12" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M18 6 6 18"/><path d="m6 6 12 12"/></svg></button>
</span>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 걸린 조건 줄은 공용/부품/ChipBar.vue — 필터 줄과 건수 줄 사이의 제 줄

## 구분
- vs Badge: 조작할 수 없으면 Badge

## 지침
- [해야 할 것] Badge는 읽기 전용, Chip은 조작 가능 — 이 구분을 지킵니다.
- [접근성] ✕ 버튼에 aria-label="Remove"를 붙입니다.

## 접근성
키보드: Tab=칩 · 제거 버튼으로 이동 · Enter · Space=제거
직접 처리: 제거 버튼에 aria-label="Remove" — 무엇을 제거하는지 포함하면 더 좋음 / 제거 후 포커스를 다음 칩 또는 컨테이너로 옮기기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
