# DsBanner — Cogniterm Design System

import { DsBanner } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
화면 최상단 전역 공지 — 점검 예정, 요금제 만료.

## Props
- icon: IconName — 앞에 붙는 아이콘. 이름만 주면 알아서 그립니다.

## Slots
- #default — 공지 문구.
- #actions — 액션 버튼.
- #icon — 아이콘을 직접 그릴 때만. 기본은 icon prop으로 자동입니다.

## 사용 예
```vue
<DsBanner icon="notification">
  8월 3일 02:00~04:00 서비스 점검이 예정되어 있습니다.
  <template #actions><DsButton variant="ghost" size="sm">자세히</DsButton></template>
</DsBanner>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 쓸 수 없음 (Vuetify 없음) — 대응 부품이 없으면 먼저 물어보세요

## 구분
- vs Alert: 페이지 전체에 해당하면 Banner, 특정 영역이면 Alert

## 지침
- [해야 할 것] 화면 최상단에 하나만. 여러 개가 필요하면 우선순위가 잘못된 것입니다.

## 접근성
키보드: Tab=액션으로 이동
직접 처리: 페이지 최상단에 두고 랜드마크(role="region")로 표시 / 닫을 수 있으면 닫기 버튼에 aria-label

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
