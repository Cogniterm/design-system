# DsSpinner — Cogniterm Design System

import { DsSpinner } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
버튼 내부, 인라인 짧은 대기(2초 이내). 에이전트 작업에는 쓰지 않습니다.

## Props
- size: number = 16 — 지름(px).
- variant: 'brand' | 'current' = 'brand' — current는 글자색을 따라갑니다 — primary·danger 버튼 안에서 사용.


## 사용 예
```vue
<DsSpinner />
<DsButton variant="secondary"><DsSpinner :size="13" /> 저장 중…</DsButton>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 공용/부품/Spinner.vue · 공용/스타일/로딩.css — 버튼 안 · 혼자 서는 자리 크기가 정해져 있습니다

## 구분
- vs ThinkingIndicator: 2초 이내면 Spinner, 에이전트 작업이면 ThinkingIndicator (원칙 1)
- vs Skeleton: 자리를 미리 보여줘야 하면 Skeleton

## 지침
- [하지 말 것] 에이전트 작업에 쓰지 않습니다. ThinkingIndicator·ToolCallStep이 그 자리입니다 (원칙 1).
- [해야 할 것] 2초를 넘길 것 같으면 Skeleton이나 진행 표시로 바꿉니다.

## 접근성
직접 처리: 주변에 무엇을 기다리는지 텍스트로 함께 표시 / 2초를 넘길 것 같으면 Skeleton이나 진행 표시로 교체

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
