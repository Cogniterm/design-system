# DsToast — Cogniterm Design System

import { DsToast } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
Snackbar의 시각 부분. 큐 관리가 필요하면 Snackbar를 쓰세요.

## Props
- variant: 'success' | 'danger' = 'success' — 결과 종류.
- action: string — 후속 액션 버튼 라벨. 하나까지만.

## Events
- @action — 액션 버튼 클릭.
## Slots
- #default — 알림 문구.

## 사용 예
```vue
<DsToast variant="success" action="View" @action="open">
  에이전트를 추가했습니다.
</DsToast>

<DsToast variant="danger" action="Retry" @action="retry">
  파일이 10MB를 초과했습니다. 나누어 업로드하세요.
</DsToast>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<div class="toast success">
  <span class="t-icon"><!-- success 아이콘 svg --></span>
  <span class="t-body">에이전트를 추가했습니다.</span>
  <button class="t-action">View</button>
</div>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): window.toast() (공용/toast) · Vue 화면은 공용/부품/Toaster.vue — 생김새는 이 부품(.toast)과 같습니다

## 구분
- vs Snackbar: 알림의 생김새는 Toast 하나뿐입니다. 실제로 떠서 사라져야 하면 Snackbar가 이걸 감쌉니다

## 지침
- [해야 할 것] 에러 토스트는 무엇이 실패했고 왜인지 말합니다("10MB를 초과합니다").
- [하지 말 것] 액션을 두 개 이상 넣지 않습니다. 선택이 필요하면 Dialog입니다.
- [예외] 떠 있는 요소라 그림자 토큰(--shadow-lg)을 씁니다. 페이지 안에 놓인 것은 그림자 없이 1px 선입니다.

## 접근성
키보드: Tab=액션으로 이동
직접 처리: role="status" 부여 — DsSnackbar를 쓰면 자동입니다 / 사라지는 시간을 충분히 (4초 이상). 액션이 있으면 더 길게

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
