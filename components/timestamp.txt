# DsTimestamp — Cogniterm Design System

import { DsTimestamp } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
테이블 시각 열, 메시지 시각, 실행 기록.

## Props
- value: Date | string | number = 필수 — 시각.
- mode: 'auto'|'absolute'|'relative' = 'auto' — auto = 7일 기준 자동.


## 사용 예
```vue
<DsTimestamp :value="log.createdAt" />
<DsTimestamp :value="log.createdAt" mode="absolute" />
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<time class="ds-time" datetime="2026-08-03T09:14:00Z">2시간 전</time>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 감사·법적 기록은 mode="absolute"로 고정합니다.

## 접근성
직접 처리: 감사 기록은 absolute 고정

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
