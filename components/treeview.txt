# DsTreeview — Cogniterm Design System

import { DsTreeview } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
드라이브 폴더 트리, 문서 목차, 조직도.

## Props
- items: DsTreeNode[] = 필수 — { id, title, icon?, locked?, children? } — children으로 중첩합니다.
- modelValue: (string|number)[] = [] — 활성(선택) 노드 id (v-model).
- opened: (string|number)[] = [] — 펼쳐진 노드 id (v-model:opened).
- getChildren: (n) => T[] | undefined — 자식을 걸러서 내려줄 때(권한 없는 폴더 숨김 등). 빈 배열 · undefined면 잎.
- rowClass: (n, ctx) => unknown — 행에 덧붙일 클래스 — 선택 · 비활성 · 드롭 강조 같은 화면 고유 상태. ctx = { depth, expanded, hasChildren }.
- ariaLabel: string — 트리 전체의 이름(스크린리더).
- expandOnSelect: boolean = true — 선택하면 자식이 있는 노드를 함께 펼칩니다. false면 펼침은 셰브런만(행 클릭 = 선택 전용).

## Slots
- #prepend — 노드 아이콘 교체. 기본은 폴더(열림/닫힘)·자물쇠. { item, expanded }를 받습니다.

## 사용 예
```vue
<DsTreeview v-model="activated" v-model:opened="opened" :items="[
  { id: 1, title: '법무', children: [{ id: 2, title: '2026' }] },
]" />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 깊이가 3단계를 넘으면 검색을 함께 제공합니다.
- [하지 말 것] VTreeview로 되돌아가지 않습니다 — 들여쓰기·가이드선 통제가 안 돼 버렸습니다.

## 접근성
키보드: Tab=트리 진입 · ↑ ↓=항목 이동 · ← →=접기 · 펴기 · Enter=선택 · Home · End=처음 · 끝
직접 처리: 트리에 aria-label / 깊이가 3단계를 넘으면 검색을 함께 제공

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
