# DsDatePicker — Cogniterm Design System

import { DsDatePicker } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
폼 안의 날짜 한 칸 — 계약 만료일, 감사 로그 기간 필터.

## Props
- modelValue: Date | Date[] — v-model. mode가 range면 [시작, 종료].
- mode: 'single' | 'range' = 'single' — 하루 · 기간.
- label: string — 라벨.
- hint: string — 보조 설명.
- error: string — 에러 메시지. 있으면 에러 상태.
- placeholder: string = '날짜 선택' — 비었을 때 문구.
- size: 'sm' | 'default' = 'default' — 32 / 40px — 필터 바·툴바는 sm.
- clearable: boolean = false — 지우기 버튼.
- presets: [string, number][] — 기간 프리셋. 예: [['최근 7일', 7]].
- min · max · disablePast · disableFuture: — — Calendar와 같습니다.


## 사용 예
```vue
<DsDatePicker
  v-model="period" mode="range" label="조회 기간"
  :presets="[['최근 7일', 7], ['최근 30일', 30], ['최근 90일', 90]]"
  disable-future clearable />
```


## 지침
- [해야 할 것] 기간 선택에는 프리셋을 답니다. "최근 30일"을 달력에서 두 번 클릭으로 찾게 하지 않습니다.
- [해야 할 것] 고를 수 없는 범위는 min·max로 미리 막습니다. 고른 뒤에 에러로 알리지 않습니다.
- [하지 말 것] 날짜를 손으로 치게 하지 않습니다. 형식 검증과 오타 안내가 통째로 따라옵니다.

## 접근성
키보드: Enter · Space=달력 열기 · ← → ↑ ↓=날짜 이동 · PageUp · PageDown=월 이동 · Enter=선택 · Esc=닫기 · 필드로 복귀
직접 처리: 고른 날짜를 필드에 글자로도 보이기 — 달력을 닫으면 격자는 사라집니다 / label을 필드에 연결하고, 에러는 aria-describedby로 함께 읽히게

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
