# DsFileInput — Cogniterm Design System

import { DsFileInput } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
문서 업로드, 로고 교체.

## Props
- modelValue: File | File[] — v-model.
- label: string — 라벨.
- accept: string — 허용 확장자.
- multiple: boolean = false — 여러 개 선택.
- error: string — 에러 메시지.
- size: 'sm' | 'default' = 'default' — 컨트롤 스케일 32 / 40px. 필터 바·툴바는 sm.


## 사용 예
```vue
<DsFileInput v-model="file" label="문서 업로드"
  accept=".pdf,.docx" hint="PDF·DOCX · 최대 10MB" :error="sizeError" />
```


## 지침
- [해야 할 것] 허용 형식과 최대 크기를 hint에 미리 적습니다. 실패 후에 알리지 않습니다.

## 접근성
키보드: Tab=필드로 이동 · Enter · Space=파일 선택 창 열기
직접 처리: 허용 형식·최대 크기를 hint에 미리 표시 / 드래그 앤 드롭만 제공하지 않기 — 버튼도 함께 / 업로드 진행률을 aria-live로

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
