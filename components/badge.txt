# DsBadge — Cogniterm Design System

import { DsBadge } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
테이블 상태 열, 목록 항목의 상태 표시. 읽기 전용.

## Props
- variant: 'default' | 'brand' | 'success' | 'warning' | 'danger' = 'default' — 상태 색.
  색 점 없이 배경·글자·테두리 색으로 구분합니다.

## Slots
- #default — 상태 텍스트.

## 사용 예
```vue
<DsBadge>Draft</DsBadge>
<DsBadge variant="brand">Running</DsBadge>
<DsBadge variant="success">Completed</DsBadge>
<DsBadge variant="warning">Delayed</DsBadge>
<DsBadge variant="danger">Failed</DsBadge>
```

## 구분
- vs Chip: Badge는 읽기 전용, Chip은 제거 가능

## 지침
- [해야 할 것] 상태별 색(배경·글자·테두리)으로 구분하고, 라벨 텍스트를 항상 함께 씁니다.
- [하지 말 것] 색만으로 상태를 구분하지 않습니다. 텍스트를 항상 함께 씁니다(색맹 대응).

## 접근성
직접 처리: 텍스트를 반드시 넣기 (색만으로 구분하지 않기) / 상태가 바뀌면 aria-live로 알릴지 검토

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
