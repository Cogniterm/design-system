# DsBadge — Cogniterm Design System

import { DsBadge } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
테이블 상태 열, 목록 항목의 상태 표시. 읽기 전용.

## Props
- variant: 'default' | 'brand' | 'success' | 'warning' | 'danger' | 'info' | 'cat-2' | 'cat-3' | 'cat-5' = 'default' — 톤 — 앞의 여섯은 의미색, 뒤의 셋은 분류용(베타·신규 같은 라벨). 분류용은 색 이름이 아니라 범주 팔레트의 슬롯 번호입니다 — 값이 바뀌어도 이름이 안 틀립니다.
- appearance: 'subtle' | 'solid' | 'outline' = 'subtle' — 외형 — subtle은 면만(테두리 없음), solid는 채움, outline은 테두리만.
- size: 'default' | 'sm' = 'default' — 22px / 18px.

## Slots
- #default — 상태 텍스트.

## 사용 예
```vue
<DsBadge>대기</DsBadge>
<DsBadge variant="brand">실행중</DsBadge>
<DsBadge variant="success" appearance="solid">완료</DsBadge>
<DsBadge variant="danger" appearance="outline">실패</DsBadge>
<DsBadge variant="cat-3" size="sm">베타</DsBadge>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<span class="badge">대기</span>
<span class="badge brand">실행중</span>
<span class="badge success solid">완료</span>
<span class="badge danger outline">실패</span>
<span class="badge cat-3 sm">베타</span>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)

## 구분
- vs Chip: Badge는 읽기 전용, Chip은 제거 가능
- vs Status: 지금 상태(정상 · 일시정지)는 Status, 한 번의 결과(완료 · 실패)는 Badge

## 지침
- [해야 할 것] 상태별 색(배경·글자·테두리)으로 구분하고, 라벨 텍스트를 항상 함께 씁니다.
- [하지 말 것] 색만으로 상태를 구분하지 않습니다. 텍스트를 항상 함께 씁니다(색맹 대응).

## 접근성
직접 처리: 텍스트를 반드시 넣기 (색만으로 구분하지 않기) / 상태가 바뀌면 aria-live로 알릴지 검토

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
