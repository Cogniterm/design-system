# DsSearchResult — Cogniterm Design System

import { DsSearchResult } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
검색 화면, 문서 찾기 결과.

## Props
- title: string = 필수 — 문서 제목.
- path: string — 경로 (예: Drive / 법무 / 2026).
- href: string = '#' — 링크.

## Slots
- #default — 매칭 문맥. 로 검색어를 감쌉니다.
- #footer — 배지·날짜 등.

## 사용 예
```vue
<DsSearchResult title="계약서_최종.pdf" path="Drive / 법무 / 2026">
  본 <mark>계약서</mark>는 2026년 7월 1일부터 효력이 발생하며…
  <template #footer>
    <DsBadge variant="success">Signed</DsBadge>
  </template>
</DsSearchResult>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<div class="sresult">
  <h4><a href="#">계약서_최종.pdf</a></h4>
  <div class="s-path">Drive / 법무 / 2026</div>
  <p>본 <mark>계약서</mark>는 2026년 7월 1일부터…</p>
</div>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 하이라이트는 브랜드 subtle 배경으로 조용하게. 형광펜처럼 쓰지 않습니다.

## 접근성
키보드: Tab=결과 제목으로 이동
직접 처리: 결과 목록을 <ol>로 마크업 / 결과 개수를 aria-live로 알리기 / <mark> 하이라이트는 스크린리더가 읽지 않으므로 문맥이 스스로 이해되게

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
