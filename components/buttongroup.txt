# DsButtonGroup — Cogniterm Design System

import { DsButtonGroup } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
그리드/리스트 보기 전환, 기간(일·주·월), 밀도 전환.

## Props
- modelValue: any — v-model.
- items: { value, label }[] = 필수 — 선택지.
- size: 'sm' | 'default' | 'lg' = 'default' — 높이 32(기본) / 40(lg).


## 사용 예
```vue
<DsButtonGroup v-model="view" :items="[
  { value: 'list', label: '리스트' },
  { value: 'grid', label: '그리드' },
]" />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)

## 구분
- vs Tabs: 내용이 통째로 바뀌면 Tabs

## 지침
- [해야 할 것] 선택지는 2~5개 · 짧은 라벨까지. 그 이상이거나 라벨이 길면 Select를 씁니다.
- [해야 할 것] 켜진 칸은 흰 면 + 브랜드 1px 링 + 브랜드 글자(--nav-active). 면을 브랜드로 채우지 않습니다.
- [하지 말 것] 한 줄에서 하나 고르는 값이 여러 줄에 걸치면 세그먼티드가 아니라 매트릭스입니다 — 줄끼리 열이 안 맞습니다.
- [하지 말 것] 페이지를 바꾸는 내비게이션으로 쓰지 않습니다. 그건 Tabs입니다.

## 접근성
키보드: Tab=그룹으로 진입 · ← →=항목 이동 · Enter · Space=선택
직접 처리: 각 버튼의 라벨을 명확히 — 아이콘만이면 aria-label / 그룹 자체에 aria-label로 무엇을 고르는지 설명

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
