# DsTabs — Cogniterm Design System

import { DsTabs } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
상세 화면 섹션 전환(개요·활동·설정), 로그 수준 필터.

## Props
- modelValue: any — v-model.
- items: { value, label, count? }[] = 필수 — count는 처리하면 줄어드는 대기열(미답변 등)에만 줍니다.


## 사용 예
```vue
<DsTabs v-model="tab" :items="[
  { value: 'all', label: '전체', count: 12 },
  { value: 'error', label: '실패', count: 3 },
]" />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): .tabs > button (공용/스타일/ui.css) — 활성은 .on — --nav-active 밑줄 + 글자. 건수는 .tabcnt

## 구분
- vs ButtonGroup: 페이지 섹션 전환이면 Tabs, 같은 데이터의 보기 전환이면 ButtonGroup

## 지침
- [해야 할 것] 탭은 같은 대상의 다른 단면일 때만. 다른 대상이면 내비게이션입니다.
- [하지 말 것] 탭 안에 탭을 넣지 않습니다.
- [하지 말 것] 탭마다 건수 배지를 달지 않습니다 — 건수는 목록 위 한 곳. 줄어드는 대기열만 예외.
- [해야 할 것] 페이지 탭은 밑줄 탭, 화면 안 보기 전환은 세그먼티드. 탭 줄 아래에 선 · 여백을 또 두지 않습니다.
- [해야 할 것] 활성 탭은 브랜드 글자 + 브랜드 밑줄(--nav-active). 면은 그대로.

## 접근성
키보드: Tab=탭 목록으로 진입 · ← →=탭 이동 · Home · End=첫 · 마지막 · Enter · Space=선택
직접 처리: 탭 이름을 짧게 — 줄바꿈되면 읽기 어려움

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
