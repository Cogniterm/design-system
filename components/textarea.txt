# DsTextarea — Cogniterm Design System

import { DsTextarea } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
설명·메모 입력, 프롬프트 편집. (대화 입력은 AgentInput)

## Props
- modelValue: string — v-model.
- label: string — 라벨.
- hint: string — 보조 설명.
- error: string — 에러 메시지.
- rows: number = 3 — 초기 줄 수. 내용이 늘면 자동 확장.


## 사용 예
```vue
<DsTextarea v-model="memo" label="메모" hint="줄이 늘면 자동으로 커집니다." />
```

## 구분
- vs AgentInput: 에이전트 대화 입력이면 AgentInput

## 지침
- [하지 말 것] 에이전트 대화 입력에는 쓰지 않습니다. 그건 AgentInput입니다.

## 접근성
키보드: Tab=필드로 이동 · Enter=줄바꿈
직접 처리: label 채우기 / 글자 수 제한이 있으면 남은 수를 aria-live로 알리기

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://kimjiyong995-coder.github.io/design-system/llms.txt
