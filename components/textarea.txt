# DsTextarea — Cogniterm Design System

import { DsTextarea } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
설명·메모 입력, 프롬프트 편집. (대화 입력은 AgentInput)

## Props
- modelValue: string — v-model.
- label: string — 라벨.
- hint: string — 보조 설명.
- error: string — 에러 메시지.
- rows: number = 3 — 초기 줄 수. 내용이 늘면 자동 확장.
- placeholder: string — 비었을 때 문구.
- size: 'sm' | 'default' = 'default' — 높이 — 기본 32. 제품의 컨트롤은 기본 32 · sm 28 · lg 40(로그인 · 큰 검색칸)입니다.


## 사용 예
```vue
<DsTextarea v-model="memo" label="메모" hint="줄이 늘면 자동으로 커집니다." />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 쓸 수 없음 (Vuetify 없음) — 대응 부품이 없으면 먼저 물어보세요

## 구분
- vs AgentInput: 에이전트 대화 입력이면 AgentInput

## 지침
- [하지 말 것] 에이전트 대화 입력에는 쓰지 않습니다. 그건 AgentInput입니다.

## 접근성
키보드: Tab=필드로 이동 · Enter=줄바꿈
직접 처리: label 채우기 / 글자 수 제한이 있으면 남은 수를 aria-live로 알리기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
