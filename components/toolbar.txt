# DsToolbar — Cogniterm Design System

import { DsToolbar } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
테이블 위 컨트롤 줄, 상세 헤더 액션 줄.

## Props
- dense: boolean = false — 40px 줄 (기본 48).
- label: string — 화면에 툴바가 둘 이상이면 구분할 이름.
- size: 'sm' | 'default' = 'default' — 컨트롤 스케일 32 / 40px. 필터 바·툴바는 sm.

## Slots
- #default — 컨트롤들. .sep(구분) · .spacer(밀기) 사용 가능.

## 사용 예
```vue
<DsToolbar dense>
  <DsButton variant="secondary" size="sm">필터</DsButton>
  <span class="sep"></span>
  <span class="spacer"></span>
  <DsButton size="sm">에이전트 추가</DsButton>
</DsToolbar>
```


## 지침
- [해야 할 것] 툴바 안 컨트롤은 전부 sm(32px).

## 접근성
키보드: Tab=컨트롤 순회
직접 처리: 컨트롤은 전부 sm — 높이 혼재 금지

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
