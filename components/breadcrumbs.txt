# DsBreadcrumbs — Cogniterm Design System

import { DsBreadcrumbs } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
드라이브 폴더 경로, 설정 하위 페이지.

## Props
- items: { title, to?, disabled?, index? }[] = 필수 — to가 있으면 링크, 없으면 @select로 클릭 이동. 마지막·disabled 항목은 현재 위치.

## Events
- @select (number) — to 없는 항목 클릭 시 그 index. 라우터 없이 이동할 때.

## 사용 예
```vue
<DsBreadcrumbs :items="[
  { title: 'Drive' }, { title: '법무' }, { title: '2026', disabled: true },
]" />
```

## 접근성
키보드: Tab=각 항목으로 이동
직접 처리: nav에 aria-label="경로" / 마지막 항목은 링크가 아니라 현재 위치 — aria-current="page"

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
