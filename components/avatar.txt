# DsAvatar — Cogniterm Design System

import { DsAvatar } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
사용자·에이전트 표시. 이름과 함께 씁니다.

## Props
- size: 'sm' | 'default' | 'lg' = 'default' — 24 / 32 / 44px.
- variant: 'default' | 'brand' = 'default' — brand는 에이전트를 뜻합니다.
- src: string — 이미지 URL. 없으면 슬롯의 이니셜을 표시합니다.

## Slots
- #default — 이니셜 텍스트 (2글자 권장).

## 사용 예
```vue
<DsAvatar>JK</DsAvatar>
<DsAvatar size="sm">JK</DsAvatar>
<DsAvatar size="lg">JK</DsAvatar>
<DsAvatar variant="brand">A</DsAvatar>
<DsAvatar src="/photo.jpg" />
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<span class="ds-avatar">JK</span>
<span class="ds-avatar sm">JK</span>
<span class="ds-avatar lg">JK</span>
<span class="ds-avatar brand">A</span>

<span class="avatar-group">
  <span class="ds-avatar">JK</span><span class="ds-avatar">MP</span><span class="ds-avatar">+3</span>
</span>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 에이전트는 brand, 사람은 기본 회색으로 구분합니다.
- [하지 말 것] 아바타만으로 사람을 식별하게 하지 않습니다. 이름을 함께 보여주거나 Tooltip을 답니다.

## 접근성
직접 처리: 아바타만으로 사람을 식별하게 하지 않기 — 이름을 함께 표시 / 이미지에는 의미 있는 alt 또는 빈 alt

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
