# DsInput — Cogniterm Design System

import { DsInput } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
한 줄 입력 전부. 에러 상태는 필수.

## Props
- modelValue: string — v-model로 바인딩.
- label: string — 필드 위 라벨.
- hint: string — 보조 설명. error가 있으면 숨겨집니다.
- error: string — 에러 메시지. 있으면 에러 상태가 됩니다.
- placeholder: string — 입력 예시.
- type: string = 'text' — HTML input type.
- size: 'sm' | 'default' = 'default' — 높이 — 기본 32. 제품의 컨트롤은 기본 32 · sm 28 · lg 40(로그인 · 큰 검색칸)입니다.


## 사용 예
```vue
<DsInput v-model="name" label="Workspace name"
  placeholder="Acme Inc." hint="모든 구성원에게 표시됩니다." />

<DsInput v-model="email" label="Email"
  :error="emailError" />
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<div class="field">
  <label>Workspace name</label>
  <input class="input" placeholder="Acme Inc." />
  <div class="hint">모든 구성원에게 표시됩니다.</div>
</div>

<!-- 에러 상태 -->
<input class="input error" />
<div class="hint error">올바른 이메일 주소를 입력하세요.</div>
```

## 앱별

- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 에러는 무엇이 잘못됐고 어떻게 고치는지 말합니다. 사과하지 않습니다.
- [하지 말 것] "입력값이 올바르지 않습니다" 같은 모호한 메시지를 쓰지 않습니다.
- [접근성] label은 항상 붙입니다. placeholder를 라벨 대신 쓰지 않습니다.

## 접근성
키보드: Tab=필드로 이동 · Esc=입력 취소 (구현 시)
직접 처리: label을 반드시 채우기 — placeholder로 대신하지 않음 / 에러 메시지를 구체적으로

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
