# DsList — Cogniterm Design System

import { DsList } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
설정 항목, 선택 가능한 항목 나열. (파일은 FileRow, 고정 열은 DataTable)

## Props
- modelValue: any — v-model — 선택된 항목의 value 하나.
- items: ListItem[] = 필수 — { value?, title, subtitle?, icon?, meta? } — icon은 이름만 주면 그려집니다.
- selectable: boolean = false — 선택 가능 여부 (시각 표시).

## Slots
- #icon — 아이콘을 직접 그릴 때만. 기본은 item.icon으로 자동입니다.

## 사용 예
```vue
<DsList :items="[
  { value: 'a', title: '자동 분류', subtitle: '규칙에 따라 분류', icon: 'run', meta: '켜짐' },
]" selectable />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 쓸 수 없음 (Vuetify 없음) — 대응 부품이 없으면 먼저 물어보세요

## 구분
- vs DataTable: 정렬·필터가 필요해지면 DataTable로 바꿉니다

## 지침
- [해야 할 것] 정렬·필터가 필요해지면 DataTable로 바꿉니다.

## 접근성
키보드: Tab=목록 진입 · ↑ ↓=항목 이동 (선택 가능할 때) · Enter · Space=선택
직접 처리: 목록에 aria-label로 무엇의 목록인지 / meta 텍스트가 상태라면 색만으로 구분하지 않기

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
