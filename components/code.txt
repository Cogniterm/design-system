# DsCode — Cogniterm Design System

import { DsCode } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
식별자·페이로드·API 응답 표기.

## Props
- block: boolean = false — 블록 형태 + 복사 버튼.
- copyable: boolean = true — 블록일 때 복사 버튼.

## Slots
- #default — 코드 내용.

## 사용 예
```vue
<DsCode>agent.run()</DsCode>
<DsCode block>const result = await agent.run()</DsCode>
```

## HTML 문법 — Vue 없이 문자열로 그리는 화면
```html
<code class="ds-code">agent.run()</code>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 이 부품 그대로 (~/design · html 문법)


## 지침
- [해야 할 것] 툴콜 페이로드·API 응답은 블록으로, 식별자 언급은 인라인으로.

## 접근성
키보드: Tab=복사 버튼으로 (블록)
직접 처리: 긴 페이로드는 접기(Accordion)와 조합

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
