# DsCode — Cogniterm Design System

import { DsCode } from '~/design'   // Vuetify 불필요 · ds.css만

## 용도
식별자·페이로드·API 응답 표기.

## Props
- block: boolean = false — 블록 형태 + 복사 버튼.
- copyable: boolean = true — 블록일 때 복사 버튼.

## Slots
- #default — 코드 내용.

## 사용 예
```vue
<DsCode>agent.run()</DsCode>
<DsCode block>const result = await agent.run()</DsCode>
```


## 지침
- [해야 할 것] 툴콜 페이로드·API 응답은 블록으로, 식별자 언급은 인라인으로.

## 접근성
키보드: Tab=복사 버튼으로 (블록)
직접 처리: 긴 페이로드는 접기(Accordion)와 조합

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://kimjiyong995-coder.github.io/design-system/llms.txt
