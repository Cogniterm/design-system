# DsCombobox — Cogniterm Design System

import { DsCombobox } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
태그·수신자 — 자유 입력 + 제안.

## Props
- modelValue: string[] = [] — v-model — 칩 배열.
- items: string[] — 제안 목록.
- label / hint / error: string — 필드 공통.
- placeholder: string — 비었을 때 문구.
- size: 'sm' | 'default' = 'default' — 컨트롤 스케일 — 기본 32 / md 36 / lg 40 (sm은 32의 다른 이름).


## 사용 예
```vue
<DsCombobox v-model="tags" label="태그" :items="suggested" />
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 쓸 수 없음 (Vuetify 없음) — 대응 부품이 없으면 먼저 물어보세요

## 지침
- [해야 할 것] 목록의 값만 허용해야 하면 Autocomplete를 씁니다.

## 접근성
키보드: 글자=입력·검색 · Enter=칩 확정 · Backspace=마지막 칩 제거 · ↑ ↓=제안 이동
직접 처리: 허용 형식 안내 (이메일 등)

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
