# DsRadioGroup — Cogniterm Design System

import { DsRadioGroup } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
배타적 설정 — 보존 기간, 공개 범위.

## Props
- modelValue: any — v-model.
- label: string — 그룹 라벨.
- items: { value, label, hint? }[] = 필수 — 선택지.
- inline: boolean = false — 가로 배치.


## 사용 예
```vue
<DsRadioGroup v-model="retention" label="보존 기간" :items="[
  { value: '90', label: '90일', hint: '기본값' },
  { value: '180', label: '180일', hint: '현재 설정' },
]" />
```


## 지침
- [해야 할 것] 선택지가 5개를 넘으면 Select를 검토합니다.

## 접근성
키보드: Tab=그룹으로 진입 (선택된 항목) · ↑ ↓ ← →=항목 이동 — 이동하면 바로 선택됨 · Space=선택
직접 처리: 그룹 label 채우기 / 기본 선택을 지정 — 빈 상태로 두지 않기

## 시스템 규칙 (요약)
- 색·간격·모서리는 CSS 변수만 (var(--gray-6), var(--brand)) — hex 금지
- primary 버튼은 화면당 하나. 선택·활성 상태는 중립(--sel-bg/--sel-fg)
- 컨트롤 높이 32(sm)/40/48 — 필터 바·툴바는 sm
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://kimjiyong995-coder.github.io/design-system/llms.txt
