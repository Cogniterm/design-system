# DsAccordion — Cogniterm Design System

import { DsAccordion } from '~/design/vuetify'   // Vuetify 필요 · ds.css + ds-vuetify.css

## 용도
툴콜 원본 페이로드, 고급 설정, FAQ. (원칙 4의 "접기")

## Props
- items: { title, text? }[] = 필수 — 패널 목록.
- modelValue: number | number[] — 펼친 패널 (v-model).

## Slots
- #item-N — N번째 패널의 내용(텍스트 대신 컴포넌트를 넣을 때).

## 사용 예
```vue
<DsAccordion v-model="open" :items="[
  { title: '원본 페이로드 보기' },
]">
  <template #item-0><pre>{{ payload }}</pre></template>
</DsAccordion>
```

## 앱별
- 이용자 화면 (Vuetify 있음): 이 부품 그대로
- 관리자 콘솔 (Vuetify 없음): 쓸 수 없음 (Vuetify 없음) — 대응 부품이 없으면 먼저 물어보세요


## 지침
- [해야 할 것] 기본은 접힌 상태로 둡니다. 중요한 정보라면 접지 않습니다.
- [하지 말 것] 에러 메시지를 접어두지 않습니다.

## 접근성
키보드: Tab=헤더로 이동 · Enter · Space=펴고 접기
직접 처리: 에러 메시지를 접어두지 않기 / 기본은 접힌 상태로

## 시스템 규칙 (요약)
- 색·간격·모서리는 제품 토큰만 (var(--border), var(--primary), var(--r-el)) — hex 금지. --brand · --sel-bg 는 문서 사이트 전용이라 앱에 없습니다
- primary 버튼은 화면당 하나. 활성(탭·필터)은 --nav-active 선+글자, 목록 행 선택은 --selected-fill 회색 면
- 컨트롤 높이 32(기본) / 28(sm — 필터 바·툴바) / 40(lg — 로그인 제출 전용)
- 목록·테이블은 default/loading/empty/error/partial 5상태
- 전체 규칙: https://Cogniterm.github.io/design-system/llms.txt
