# Forms (폼) — Cogniterm Design System pattern

> 입력을 받고 검증하고 저장합니다.
> Group: Core (기본) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

## 구조

라벨 → 입력 → 힌트 순으로 **6px 간격**으로 붙여 한 덩어리로 만들고, 필드 사이는 **20px**로 띄웁니다. 이 차이가 무엇이 한 묶음인지 알려줍니다.

## 검증은 언제

| 시점 | 쓰는 곳 |
|---|---|
| **제출할 때** (기본) | 대부분의 폼. 입력 중에 빨간 줄이 뜨면 방해가 됩니다. |
| **필드를 벗어날 때** | 형식이 정해진 값 — 이메일, 전화번호 |
| **입력하는 중** | 실시간 확인이 필요한 것 — 비밀번호 강도, 중복 검사 |

`defaults.ts`가 `VForm`의 `validateOn`을 `submit`으로 고정합니다.

## 에러 처리

- 필드 에러는 **그 필드 아래**에 둡니다. 위에 모아두면 어느 필드인지 찾아야 합니다.
- 에러가 3개를 넘으면 폼 **상단에 Alert**로 요약하고, 각 필드에도 표시합니다.
- 제출 실패 시 **첫 에러 필드로 포커스**를 옮깁니다.
- 입력한 값은 **지우지 않습니다**. 다시 치게 만들지 마세요.

## 저장 상태

**해야 할 것**

- 저장 중에는 버튼을 `disabled` + Spinner로
- 완료는 Snackbar로 짧게
- 자동 저장이면 "저장됨 · 방금" 같은 조용한 표시

**하지 말 것**

- 저장 성공을 Dialog로 알리기 — 흐름을 끊습니다
- 필수 항목을 `*`로만 표시 — "(필수)"라고 씁니다
- 취소 버튼을 primary로

## 값을 고르는 컨트롤

| 값 | 컨트롤 |
|---|---|
| 2~5개 · 짧은 라벨 | **세그먼티드** — 다 보여 줍니다. 사다리(이용 ⊂ 편집)면 차례대로 |
| 그보다 많거나 라벨이 김 | DsSelect (드롭다운) |
| 한 줄에서 하나 고르는 값이 **여러 줄**에 걸침 | **매트릭스** — 줄끼리 열이 맞아 세로로 훑을 수 있습니다 |
| 표 안에서 상태를 바꾸는 칸 | **태그 드롭다운** — 배지 모양 + 셰브런. 테두리 있는 Select를 넣지 않습니다 |
| 날짜 | DS 달력 — readonly 트리거 + 팝오버 |

- **네이티브 `<select>` · `<input type="date">`를 쓰지 않습니다.** 시스템 UI는 글꼴 · 줄 높이 · 라운드가 달라 그 칸만 결이 어긋납니다. 파일 고르기만 예외입니다.
- 못 고르는 값은 지우지 말고 **잠급니다** — 지우면 칸 수가 달라져 줄이 어긋나고, 왜 잠겼는지는 툴팁이 말합니다.
- **화면의 뜻을 뒤집는 토글을 두지 않습니다.** 누르면 왼쪽 · 오른쪽이 자리를 바꾸는 전환은 매번 "지금 어느 쪽이지"를 되짚게 합니다. 반대 방향은 그 대상의 화면에 읽기 전용으로 답니다.

## 한글 입력 (IME)

- **치는 대로 거르는 칸에 Vue `v-model`을 쓰지 않습니다.** 한글은 음절이 끝나야 조합이 끝나 'ㅈ' 한 글자가 영영 안 올라오고, 마지막 음절은 늘 빠집니다. `:value` + `@input`으로 입력칸의 값을 직접 읽습니다(제품의 `imeValue($event)`).
- **치고 있는 입력칸을 다시 그리지 않습니다.** 칸이 새 노드로 바뀌면 조합이 그 자리에서 확정돼 '인사'가 'ㅇㅣㄴㅅㅏ'가 됩니다. 검색어에 딸린 **목록만** 갈아 끼웁니다.
- 제출할 때 한 번 읽는 칸(이름 · 메모 · 답변)은 `v-model` 그대로 둡니다.

## 쓰는 컴포넌트
