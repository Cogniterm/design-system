# Loading & Empty & Error (로딩 · 빈 · 에러) — Cogniterm Design System pattern

> 데이터가 없거나 실패했을 때의 다섯 가지 상태.
> Group: Core (기본) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

**모든 목록·테이블·검색 화면은 다섯 상태를 전부 가집니다.** 나중에 추가하는 비용이 처음부터 만드는 것보다 훨씬 큽니다.

## 다섯 상태

| 상태 | 쓰는 것 | 주의 |
|---|---|---|
| `default` | — | |
| `loading` | Skeleton (에이전트면 ThinkingIndicator) | 실제 콘텐츠와 비슷한 크기·개수로 |
| `empty` | EmptyState | **다음 행동을 반드시 제안** |
| `error` | Alert + 재시도 | 사과하지 않고 무엇을 할 수 있는지 |
| `partial` | Alert(warning) + 성공분 표시 | 가장 자주 빠뜨립니다 |

## 빈 상태는 네 종류입니다

같은 문구로 처리하면 사용자는 무엇을 해야 할지 알 수 없습니다.

| 종류 | 문구 | 액션 |
|---|---|---|
| 아직 만든 적 없음 | "에이전트가 없습니다" | 만들기 |
| 검색 결과 없음 | "'회의록 2019'에 대한 결과가 없습니다" | 검색어 수정 안내 |
| 필터로 걸러짐 | "조건에 맞는 항목이 없습니다" | **필터 해제** |
| 권한 없음 | "이 폴더를 볼 권한이 없습니다" | 권한 요청 |

## partial — 에이전트 제품의 필수 상태

"문서 10건 중 7건만 읽었다"는 상황이 흔합니다. 전부 실패로 처리하면 읽은 7건이 낭비되고, 성공으로 처리하면 사용자가 속습니다.
