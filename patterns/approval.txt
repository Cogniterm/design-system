# Human in the Loop (사람의 승인) — Cogniterm Design System pattern

> 에이전트가 되돌릴 수 없는 일을 하기 전에 멈춥니다.
> Group: Agent (에이전트) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

## 언제 멈추나

| 행동 | 처리 |
|---|---|
| 읽기 · 검색 · 요약 | 그냥 실행. 승인 불필요 |
| 파일 생성 · 수정 | 실행 후 **되돌리기** 제공 |
| 삭제 · 외부 전송 · 결제 | **실행 전 승인** |
| 권한 변경 · 대량 작업 | **실행 전 승인 + 영향 범위 명시** |

## 승인 요청의 모양

## 규칙

- **무엇을 할지 구체적으로** 나열합니다. "파일을 정리할까요?"가 아니라 파일 이름을 보여줍니다.
- 대상이 많으면 **개수 + 처음 몇 개 + "외 N건"**으로 보여주고 펼칠 수 있게 합니다.
- 승인을 기다리는 동안 **다른 작업은 계속**합니다. 전체를 멈추지 않습니다.
- 거절하면 **이유를 물어보고** 그 맥락으로 다시 시도할 수 있게 합니다.
- "항상 허용"을 제공하되 **범위를 좁게** — "이 폴더에서만", "이 대화에서만".
