# Chat / Agent (챗 · 에이전트) — Cogniterm Design System pattern

> 에이전트와 대화하는 화면.
> Group: Page Templates (페이지 템플릿) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

## 골격

```
좌: 대화 목록    우: 메시지 스트림
                    ├ 사용자 메시지
                    ├ 툴콜 (본문 위)
                    ├ 응답 + 인용
                    └ 입력창 (하단 고정)
```

- **본문 너비는 720px을 넘기지 않습니다.** 한 줄이 길면 다음 줄 첫 글자를 찾기 어렵습니다.
- 툴콜은 **본문 위**에. 근거가 답보다 먼저 보여야 합니다.
- 입력창은 하단 고정. Enter 전송, Shift+Enter 줄바꿈.
- 긴 산출물은 인라인 대신 **ArtifactPanel**로 분리합니다.
