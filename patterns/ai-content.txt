# AI Content Labeling (AI 생성 표시) — Cogniterm Design System pattern

> 무엇이 AI가 만든 것인지 구분합니다.
> Group: Agent (에이전트) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

**사용자가 화면의 어떤 부분을 신뢰해야 할지 알 수 있어야 합니다.** 원본 데이터와 AI가 만든 내용이 같은 모양이면 구분할 수 없습니다.

## 표시 방법

| 상황 | 표시 |
|---|---|
| 대화 안의 응답 | 아바타가 이미 구분 — 추가 표시 불필요 |
| 일반 화면에 삽입된 요약 | **배지** + 조용한 브랜드 배경 |
| AI가 채운 폼 값 | 필드 옆 배지 + "확인하세요" 힌트 |
| AI 생성 중 | Skeleton이 아니라 **ThinkingIndicator** |

## 규칙

- **AI 배지는 브랜드 subtle 배경**으로 조용하게. 경고색을 쓰지 않습니다 — 위험한 게 아니라 출처가 다를 뿐입니다.
- **무엇을 근거로 만들었는지** 함께 표시합니다 — "3개 문서 기반".
- 사용자가 **수정하면 배지를 제거**합니다. 더 이상 AI 생성물이 아닙니다.
- 확신이 낮으면 **말로 표현**합니다 — "문서에서 명확하지 않습니다". 확률 퍼센트는 대부분 도움이 되지 않습니다.
