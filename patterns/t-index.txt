# Index Page (목록 화면) — Cogniterm Design System pattern

> 데이터를 나열하고 찾는 화면.
> Group: Page Templates (페이지 템플릿) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

## 골격

```
제목 (20px/600)                 [＋ 사용자 추가] [사용자 편집]   ← 제목줄: 만들기 · 편집 · 저장 · 실행
밑줄 탭 (있으면)                                                  ← 아래에 선 · 여백을 또 두지 않음
[필터] [검색]  보기 전환                건수 · [표 열 설정]         ← 필터줄: 거르는 것만
조건 칩 줄 (걸린 게 있을 때만)
─────────────────────────
표 — 머리 40 · 줄 52
쪽 발 — 1–20 / 500명   ‹ 1 2 3 ›                                  ← 판 바닥에 붙박음
```

## 버튼의 자리

- **만들기 · 편집 · 저장 · 실행은 제목줄 오른쪽**. 프라이머리는 화면에 **하나**입니다 — 편집이 있는 화면은 [○○ 편집]이 프라이머리이고 편집 중에는 그 자리를 [저장]이 물려받습니다.
- **필터줄은 보이는 것을 고르는 것뿐** — 왼쪽부터 필터 · 검색 · 보기 전환, 오른쪽 끝은 건수 → [표 열 설정]. 여기에 만드는 버튼을 두지 않습니다. `margin-left: auto`는 한 줄에 하나만.
- 예외 — 한 화면에 카드가 여럿이면 만드는 버튼이 **그것을 담은 카드 머리 맨 끝**에 섭니다.

## 표는 두 갈래 — 한 표 안에서 섞지 않습니다

| 갈래 | 언제 | 모양 |
|---|---|---|
| **줄 클릭 표** | 줄이 곧 물건 하나이고 줄 안에 누를 것이 없음 | 줄 hover 면 + 손가락. 줄 안에서 누르는 것은 맨 끝 ⋯ · 스위치뿐. 칸 필터 없음 |
| **링크 표** | 거르면서 보는 기록 · 로그 · 이력 (칸 필터 · 체크 · 정렬이 줄에 섬) | 줄은 안 눌림. **맨 왼쪽 한 칸이 문** — 밑줄 글자, 줄에 올리면 [↗ 열기] 배지. 분류 칸은 칸 필터 |

가르는 기준은 데이터 양이 아니라 **"그 줄에 문 말고 누를 것이 있느냐"**입니다. 줄 hover는 눌러서 열리는 줄에만 겁니다.

## 정렬

- 목록 표의 머리 칸은 **전부** 오름차순 ↔ 내림차순으로 정렬됩니다.
- 기준은 **칸에 보이는 값**. 서열이 있는 값은 서열로(등급 C › S › O, 직급 차례) — 글자순이 아닙니다.
- **빈 값은 방향과 상관없이 맨 뒤**. 첫 방향은 글자 오름차순 · **수 · 일시는 내림차순**.
- 정렬을 바꾸면 쪽은 1로. 눌러도 아무 줄도 안 움직이는 열에는 달지 않습니다.

## 쪽 나눔

- 한 쪽 **20줄**. 발은 **판 바닥에 붙박이**(줄이 적어도 바닥) — 담는 칸이 세로 flex여야 합니다.
- 발의 글은 **건수가 아니라 자리** — "1–20 / 500명". 몇 건이 걸렸나는 목록 위 건수가 말합니다.
- 줄이 없으면 발을 그리지 않습니다. 새로 만든 줄은 그 줄이 있는 쪽으로 옮깁니다. 무한 스크롤을 쓰지 않습니다.
- 순위표 · 대시보드 카드 안 표 · 트리 · 차례가 값인 편집 목록은 자르지 않습니다.

## 칸

- 값이 없는 칸은 **"—"**. 사용자 칸은 **이름 / 사용자 ID(계정 전체)** 두 줄.
- 상태 · 결과 열은 오른쪽 끝, 조작 열 바로 앞. 조작 열(×)은 편집 중에만 버튼이 서도 **칸은 늘 섭니다** — 열 폭이 흔들리지 않게.
- [표 열 설정]은 열 구성을 고정할 수 없는 표에만 답니다(배포 · 회사마다 쓰는 열이 다름).

## 탭

- 화면 안 큰 갈래 = **밑줄 탭**, 그 안에서 보기를 바꾸는 것 = **세그먼티드**. 둘 다 밑줄이면 무엇이 상위인지 안 읽힙니다.
- 탭 줄 아래에 여백 · 구분선을 또 두지 않습니다. 탭 안에 탭을 두지 않습니다.
- **탭에 건수 배지를 달지 않습니다** — 처리하면 줄어드는 대기열(미답변 등)만 예외입니다.
