# Edit mode (편집 모드) — Cogniterm Design System pattern

> 여러 값을 함께 고치고 한 번에 저장합니다 — 조직 · 권한 · 직제 · 사용자 · 정책.
> Group: Core (기본) · Index: https://Cogniterm.github.io/design-system/patterns/llms.txt

## 흐름

```
읽는 중   제목                                [권한 편집]   ← 프라이머리
   ↓
편집 중   제목   ● 편집 중 · 변경 3건         [취소] [저장]  ← [저장]이 그 자리를 물려받음
   ↓ [저장]
확인 창   이대로 저장할까요?
          자원 권한 2건 · CSO 등급 1건          [더 고치기] [저장]
   ↓
토스트    저장했습니다 — 자원 권한 2건 · CSO 등급 1건
```

## 규칙

- **[○○ 편집]은 제목줄 오른쪽 · 프라이머리**입니다(○○는 화면 이름). 편집은 화면 전체에 걸리므로 탭 · 판 머리로 내리지 않습니다.
- 편집 중 표시는 한 벌 — **"● 편집 중 · 변경 N건"**(사람을 세면 "N명").
- **[취소]는 스냅샷을 통째로 되돌립니다.** 초안 자료구조를 따로 두지 않고, 들어갈 때 찍은 스냅샷을 부어 넣습니다 — 드는 상태를 하나도 빠뜨리지 않습니다.
- **건수는 스냅샷과의 차이**입니다. 동작을 세지 않습니다 — 줬다 뺐으면 0건.
- **[저장]은 확인 창**을 거칩니다 — 변경 요약 한 줄 + [더 고치기] [저장]. 무엇이 무엇으로 바뀌는지까지 적습니다. 저장 뒤 토스트가 요약을 되풀이합니다.
- **읽는 중에 값을 누르면 "편집을 시작할까요?"**를 묻습니다. 그냥 안 먹게 두면 "눌렀는데 아무 일도 안 일어나는 화면"입니다. 읽는 중의 값은 흐리지 않습니다 — 읽으라고 있는 표입니다.
- **Esc는 한 겹씩** — 창 › 서랍 › 편집.
- **저장하지 않은 채 다른 메뉴로 못 나갑니다** — "저장하지 않고 나갈까요?". 붙잡았으면 메뉴 강조도 되돌립니다.

## 하지 않는 것

- **칸마다 확인을 묻지 않습니다.** 묻는 자리는 [편집] 진입과 [저장] 둘이고, 그 사이는 [취소]가 책임집니다.
- **낱개 조작마다 토스트를 띄우지 않습니다.** 무엇이 바뀌었는지는 그 줄이, 얼마나 쌓였는지는 "변경 N건"이 말합니다. 말이 붙는 것은 줄만 봐서는 모르는 변경(상속 끊기 · 전원에 걸리는 변경)뿐입니다.
- **[실행 취소] 토스트를 함께 두지 않습니다.** 되돌리는 길은 [취소] 하나입니다.
- 낱말은 **편집**입니다 — "수정"이 아닙니다.
