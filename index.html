Design System

AI SaaS Agent 제품군을 위한 디자인 시스템입니다. Geist 계열의 극한 미니멀 스타일 — 그림자 없음, 1px 보더, 색은 회색과 브랜드 블루(#1F7FF0)만. 컴포넌트 이름은 영문, 설명은 한글로 제공합니다.

Tokens

모든 색·간격·모서리 값의 단일 원본입니다. 컴포넌트는 반드시 CSS 변수(var(--gray-3))로만 참조하고, 값을 직접 하드코딩하지 않습니다.

Button

custom — built from scratch

액션을 실행하는 기본 버튼. primary는 한 화면에 하나가 원칙입니다. 파괴적 액션(삭제 등)은 danger를 쓰되, 기본은 조용한 외곽선 형태 — 호버했을 때만 빨간 배경이 드러납니다.

<button class="btn btn-primary">New agent</button>
<button class="btn btn-secondary">Cancel</button>
<button class="btn btn-ghost">Learn more</button>
<button class="btn btn-danger">Delete</button>
<button class="btn" disabled>Disabled</button>
<button class="btn btn-primary btn-sm">Small</button>

Input

custom — built from scratch

텍스트 입력 필드. 포커스 시 브랜드 컬러 링이 생깁니다. 에러 상태는 필수 — 에러 메시지는 "무엇이 잘못됐고 어떻게 고치는지"를 말하고, 사과하지 않습니다. (VTextField는 래퍼가 깊어 직접 제작)

모든 멤버에게 표시됩니다.
올바른 이메일 주소를 입력하세요.
<div class="field">
  <label>Workspace name</label>
  <input class="input" placeholder="Acme Inc." />
  <div class="hint">모든 멤버에게 표시됩니다.</div>
</div>

<!-- 에러 상태 -->
<input class="input error" />
<div class="hint error">올바른 이메일 주소를 입력하세요.</div>

Badge

custom — built from scratch

상태 표시용 작은 라벨. 에이전트 실행 상태(대기·실행 중·완료·실패)에 주로 씁니다. 색 점(dot)이 상태를 말하고, 배경은 조용하게 유지합니다.

Draft Running Completed Failed 
<span class="badge"><span class="dot"></span>Draft</span>
<span class="badge brand"><span class="dot"></span>Running</span>
<span class="badge success"><span class="dot"></span>Completed</span>
<span class="badge danger"><span class="dot"></span>Failed</span>

Chip

custom — built from scratch

선택된 항목을 표시하고 제거할 수 있는 요소. 필터 조건, 첨부 파일, 선택된 태그 등에 씁니다. Badge는 읽기 전용, Chip은 조작 가능 — 이 구분을 지킵니다.

design-system.pdf Q3 보고서 Status: Running 
<span class="chip">
  design-system.pdf
  <button class="x" aria-label="Remove">✕</button>
</span>
<span class="chip brand">Status: Running<button class="x">✕</button></span>

Divider

custom — built from scratch

내용을 구분하는 1px 선. 극한 미니멀에서는 그림자 대신 이것으로 영역을 나눕니다. 라벨이 있는 형태는 "오늘 / 어제" 같은 날짜 구분에 씁니다.

위 내용

Skeleton

custom — built from scratch

데이터 로딩 중 실제 콘텐츠의 자리를 미리 보여주는 뼈대. 스피너보다 화면 흔들림이 적습니다. 단, 에이전트 응답 대기에는 쓰지 않습니다 — 그건 ThinkingIndicator·ToolCallStep의 몫입니다(원칙 1번).

<div class="skeleton circle" style="width:32px;height:32px"></div>
<div class="skeleton text" style="width:60%"></div>
<div class="skeleton text" style="width:90%"></div>

Toast

custom — built from scratch

작업 결과를 잠깐 알려주는 알림. 화면 우하단에 떠서 4초 후 사라집니다. 되돌리기(Undo)나 보기(View) 같은 후속 액션을 하나까지 담을 수 있습니다. 유일하게 그림자가 허용되는 컴포넌트 중 하나(떠 있는 요소이므로).

에이전트가 생성되었습니다.
파일 업로드에 실패했습니다 — 10MB를 초과합니다.

  <span class="t-dot"></span>
  <span class="t-body">에이전트가 생성되었습니다.</span>
  <button class="t-action">View</button>
</div>

ChatMessage

Not available in Vuetify — built from scratch

대화형 메시지 컴포넌트. Vuetify에 대응물이 없어 직접 만듭니다. 스트리밍 중 높이가 변하고 역방향 스크롤 앵커링이 필요해 VCard로 대체할 수 없습니다. 인용 칩(CitationChip)과 스트리밍 커서를 포함합니다.

ThinkingIndicator

ToolCallStep

Not available in Vuetify — built from scratch

에이전트가 도구를 실행하는 과정을 보여줍니다. 원칙 1번 — 빈 스피너 대신 무슨 일이 진행 중인지를 보여줍니다. 진행 중엔 스피너, 완료되면 체크로 바뀝니다. 접을 수는 있어도 없애지 않습니다(원칙 4번).

✓ search_drive("계약서", June) — 3 files found
read_document("계약서_최종.pdf")
<!-- 진행 중 -->
<div class="toolcall"><span class="spinner"></span> read_document("file.pdf")</div>

<!-- 완료 -->
<div class="toolcall"><span class="check">✓</span> search_drive("query") — 3 files found</div>

AgentInput

Not available in Vuetify — built from scratch

에이전트에게 보내는 메시지 입력창. 여러 줄 자동 확장(auto-grow), 파일 첨부, 슬래시 명령을 지원합니다. 하단 바에 도구 버튼을 두고, 보내기는 항상 오른쪽 끝.

<div class="agent-input">
  <textarea rows="1" placeholder="Message agent…"></textarea>
  <div class="ai-bar">
    <button class="ai-tool" aria-label="Attach file">＋</button>
    <button class="ai-tool" aria-label="Slash commands">/</button>
    <span class="ai-spacer"></span>
    <button class="btn btn-primary btn-sm">Send</button>
  </div>
</div>

EmptyState

custom — built from scratch

데이터가 없을 때의 화면. 극한 미니멀에서는 빈 화면이 "미완성"처럼 보이기 쉬우므로, 빈 상태는 반드시 다음 행동(CTA)을 제안합니다.

No agents yet

첫 에이전트를 만들어 업무 자동화를 시작하세요.

</div>
